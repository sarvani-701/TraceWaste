# ♻️ TraceWaste

TraceWaste is a smart e-waste management platform that encourages responsible disposal of electronic waste through guided dismantling instructions, disposal tracking, proof verification, and a reward-based credit system.

## Features

- User Signup & Login
- Device Type & Condition Selection
- Dismantling Instructions
- Reward Credit System
- Disposal Tracking Dashboard
- Proof Upload Verification
- User Profile & Credit Tracking
- Analytics Visualization

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- LocalStorage
- Recharts

## Workflow

1. User logs in or creates an account
2. Selects the e-waste device and condition
3. Views dismantling and disposal instructions
4. Marks the item as disposed
5. Earns reward credits
6. Uploads disposal proof
7. Tracks activity through the dashboard
8. Monitors credits via profile section

## Future Scope
